# Built-in Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every agent serves an HTTPS dashboard where one operator, with one
shared password, can see the cluster and approve, cancel or finalize an
upgrade, or start a rolling restart, with the same checks the CLI enforces.

**Architecture:**

- **Shared logic.** Operator actions move out of `main.rs` into `ops.rs`,
  and the read-only snapshot into `cluster_view.rs`. The CLI and the web UI
  call the same functions.
- **Web thread.** The UI is axum on a private tokio runtime in its own
  thread. The rest of the agent stays synchronous, and every DB call from
  the web layer runs in `spawn_blocking`.
- **Rolling restart.** This is a new rollout `kind`. Both reconcilers branch
  on `kind` before any upgrade logic.

**Tech Stack:**

- Rust 2024, MSRV 1.87;
- `postgres` (blocking);
- axum 0.8 and axum-server 0.8, with rustls 0.23 on `ring`;
- tokio 1 and tower-http 0.6;
- argon2 0.6, rand 0.10, subtle 2.6 and rpassword 7;
- rcgen 0.14 (dev only).

**Spec:** `docs/superpowers/specs/2026-10-10-web-ui-design.md` (v1.1.0, amended 2026-10-11)

## Global Constraints

**Runtime boundary:**

- **Tokio stays inside the web thread.**
  - `main`, the daemon loop and all CLI commands stay synchronous.
  - Never add `#[tokio::main]`.
  - The web thread builds its own runtime with
    `tokio::runtime::Builder::new_multi_thread()` and calls `block_on`.
- **Blocking clients never touch async code.**
  - A blocking `postgres::Client` and `reqwest::blocking` are only
    created, used and dropped inside a `spawn_blocking` closure. Use the
    `web::blocking` helper from Task 10.
  - Async state holds only `Arc<dyn Backend>`, `Arc<LoginLimiter>` and
    plain values, never a `Client`.
- **TLS provider.**
  - rustls uses the `ring` provider only. `cargo tree -e normal | grep -c
    aws-lc` must print `0`.
  - axum-server uses the feature `tls-rustls-no-provider`, never
    `tls-rustls`.
  - The UI never serves plain HTTP. If TLS cannot load, the UI is off and
    the daemon keeps running.

**Configuration and storage:**

- **Environment variables.** Names are exactly:
  - `CROACH_ROLLOUT_UI_LISTEN` (default `0.0.0.0:38090`, or `off`);
  - `CROACH_ROLLOUT_UI_CERTS_DIR` (default unset);
  - `CROACH_ROLLOUT_UI_SESSION_HOURS` (default `12`).
- **Login rules.**
  - The session cookie is `crra_session`, with `Secure; HttpOnly;
    SameSite=Strict; Path=/`.
  - Passwords are at least 12 characters.
  - The lockout is 5 failures per IP within 60 seconds, then 429.
- **Event retention.** Keep the newest 500 events, and show the newest 50
  on the dashboard.
- **Version guard.** The first restart-capable agent version is `0.1.0`,
  as `MIN_RESTART_AGENT_VERSION`.
- **Schema changes.** All new SQL objects live in the configured schema.
  Each schema statement runs in its own `batch_execute` (one per round
  trip), the same as the existing `ensure_schema`.

**Repo conventions:**

- **Visibility.** The crate is bin-only. New modules reach crate-root items
  as `crate::name`. A child module can see private items of the crate root,
  so do **not** make existing `main.rs` items `pub`.
- **File headers (MANDATORY).** Every file you create or modify carries the
  header in its comment syntax: `//` for Rust and JS, `/* */` for CSS,
  `<!-- -->` for Markdown, `#` for shell and env.
  - On every edit, bump `version` (minor for features, patch for fixes)
    and set `last-edited: 2026-10-11`.
  - New files start at `1.0.0` with the guid this plan gives them.
- **Commits** are conventional, `type(scope): description`, and end with
  the two trailer lines:

  ```text

  Claude-Session: https://claude.ai/code/session_01P2coHXurAM9VQCm1XCHxnS
  ```

- **Changelog.** Never edit `CHANGELOG.md`. Add a fragment under

- **Dead-code warnings** are expected between tasks, because later tasks

## Review Focus

These five inputs and failure modes are the most likely to hurt an operator.
Each one has a test in the task listed.

1. **An old agent during a rolling restart.**
   - **Situation:** a node runs a v0.0.x agent, which has no `node_id` or
     `agent_version`.
   - **Expected:** the restart is refused, and the error names the node or
     agent. → Task 2, `restart_agent_gaps_names_missing_and_old_agents`,
     and Task 5, `restart_needs_no_open_rollout_one_version_and_new_agents`.
2. **Stale gossip after `systemctl restart`.**
   - **Situation:** the node still shows live on the right version from
     before the restart.
   - **Expected:** the follower waits for a newer `started_at`.
     → Task 2, `restart_is_confirmed_only_by_a_newer_start`.
3. **Hostile text in agent errors, event details or flash messages.**
   - **Situation:** the text contains, for example, `<script>`.
   - **Expected:** it is rendered inert. → Task 7,
     `hostile_text_is_escaped_everywhere`.
4. **The session expires or is forged mid-form.**
   - **Expected:** a POST redirects to `/login` and the action never runs.
     → Task 10, `posts_with_an_unknown_session_go_to_login`.
5. **The database is unreachable while the dashboard renders.**
   - **Expected:** a "database unreachable" banner with no stale data and
     no action forms. → Task 10,
     `database_errors_show_a_banner_without_actions`.

```rust
/// What a rollout does to each node.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum RolloutKind {
    /// Swap the binary to a new version, one node at a time.
    Upgrade,
    /// Restart every node in turn on the version it already runs.
    Restart,
}

impl RolloutKind {
    pub fn as_str(self) -> &'static str {
        match self {
            Self::Upgrade => "upgrade",
            Self::Restart => "restart",
        }
    }
}

impl fmt::Display for RolloutKind {
    fn fmt(&self, formatter: &mut fmt::Formatter<'_>) -> fmt::Result {
        formatter.pad(self.as_str())
    }
}

impl FromStr for RolloutKind {
    type Err = String;

    fn from_str(value: &str) -> Result<Self, Self::Err> {
        match value {
            "upgrade" => Ok(Self::Upgrade),
            "restart" => Ok(Self::Restart),
            other => Err(format!("unknown rollout kind: {other}")),
        }
    }
}
```

```rust
/// The oldest agent release that understands `RolloutKind::Restart`. Older
/// agents ignore `kind`, so as leader they would end a restart at once and as
/// followers they would report done without restarting anything.
pub const MIN_RESTART_AGENT_VERSION: &str = "0.1.0";

/// One `agent_status` row, reduced to what the restart decisions need.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct AgentObservation {
    pub agent_id: String,
    /// The CockroachDB node the agent runs beside; `None` for agents older
    /// than `MIN_RESTART_AGENT_VERSION`, which never wrote it.
    pub node_id: Option<i64>,
    pub agent_version: Option<String>,
    pub restarted_rollout_id: Option<String>,
}

/// What a node's agent should do about an active restart.
#[derive(Debug, PartialEq, Eq)]
pub enum RestartAction {
    AlreadyRestarted,
    /// Take the install lease, pass the health gate, then restart.
    Restart,
}

pub fn restart_action(rollout_id: &str, restarted_rollout_id: Option<&str>) -> RestartAction {
    if restarted_rollout_id == Some(rollout_id) {
        RestartAction::AlreadyRestarted
    } else {
        RestartAction::Restart
    }
}

/// True when every active node is live and its agent has recorded this
/// restart. A node without a matching agent keeps the restart open, like a
/// node without an agent keeps an upgrade open.
pub fn restart_complete(
    agents: &[AgentObservation],
    nodes: &[NodeObservation],
    rollout_id: &str,
) -> bool {
    !nodes.is_empty()
        && nodes.iter().all(|node| {
            node.is_live
                && agents.iter().any(|agent| {
                    agent.node_id == Some(node.node_id)
                        && agent.restarted_rollout_id.as_deref() == Some(rollout_id)
                })
        })
}

/// Why the agents cannot run a rolling restart, one line per node; empty
/// when every node has an agent at `minimum` or newer.
pub fn restart_agent_gaps(
    agents: &[AgentObservation],
    nodes: &[NodeObservation],
    minimum: &Version,
) -> Vec<String> {
    nodes
        .iter()
        .filter_map(|node| {
            let Some(agent) = agents.iter().find(|agent| agent.node_id == Some(node.node_id))
            else {
                return Some(format!(
                    "node {} has no agent reporting its node id (agents older than {minimum} do not)",
                    node.node_id
                ));
            };
            match agent.agent_version.as_deref().map(Version::parse) {
                Some(Ok(version)) if version >= *minimum => None,
                Some(Ok(version)) => Some(format!(
                    "{} runs agent {version}; it needs {minimum} or newer",
                    agent.agent_id
                )),
                _ => Some(format!(
                    "{} has not reported an agent version; upgrade it to {minimum} or newer",
                    agent.agent_id
                )),
            }
        })
        .collect()
}

/// True once this node is back, live on `expected`, and gossip reports a
/// start time newer than the one read before `systemctl restart`. The start
/// time check rejects gossip that predates the restart.
pub fn restarted_on(
    expected: &Version,
    started_before_us: i64,
    node: &NodeObservation,
```

```rust
pub enum AvailableAction {
```

```rust
pub fn approve_precheck(
    open: Option<&OpenSummary>,
    version: &Version,
    accept_warnings: bool,
) -> Result<(), String> {
    let open = open.ok_or_else(|| "there is no proposed rollout".to_string())?;
    if open.status != RolloutStatus::Proposed {
        return Err(format!(
            "the open rollout to {} is {}, not proposed",
            open.to, open.status
        ));
    }
    if open.to != *version {
        return Err(format!("the proposal targets {}, not {version}", open.to));
    }
    if !open.warnings.is_empty() && !accept_warnings {
        return Err(format!(
            "release notes matched {:?}; review {}, then accept the release-note warnings \
             (--accept-release-note-warnings on the CLI, the checkbox in the UI)",
            open.warnings, open.release_notes_url
        ));
    }
    Ok(())
}

pub fn finalize_precheck(
    open: Option<&OpenSummary>,
    nodes: &[NodeObservation],
    version: &Version,
) -> Result<(), String> {
    reject_prerelease(version).map_err(|error| error.to_string())?;
    if let Some(open) = open {
        if open.kind == RolloutKind::Restart {
            return Err("a rolling restart is open; finalize applies to upgrades".to_string());
        }
        if open.to != *version {
            return Err(format!("the open upgrade targets {}, not {version}", open.to));
        }
    }
    if !all_nodes_on(version, nodes) {
        return Err(format!(
            "refusing to finalize: not every node is live on {version}; see status"
        ));
    }
    Ok(())
}

/// Returns the version every node will restart on.
pub fn restart_precheck(
    open: Option<&OpenSummary>,
    nodes: &[NodeObservation],
    agents: &[AgentObservation],
) -> Result<Version, String> {
    if let Some(open) = open {
        return Err(format!(
            "a {} rollout to {} is {}; finish or cancel it first",
            open.kind, open.to, open.status
        ));
    }
    let (oldest, newest) = live_version_span(nodes)?;
    if oldest != newest {
        return Err(format!(
            "nodes run {oldest} and {newest}; a rolling restart needs every node on one version"
        ));
    }
    let minimum = Version::parse(MIN_RESTART_AGENT_VERSION).expect("constant is a valid version");
    let gaps = restart_agent_gaps(agents, nodes, &minimum);
    if !gaps.is_empty() {
        return Err(format!("cannot restart safely: {}", gaps.join("; ")));
    }
    Ok(oldest)
}

/// Actions valid for `view`. The server runs the matching precheck again on
/// POST, because the view may be stale by then.
pub fn available_actions(view: &ClusterView) -> Vec<AvailableAction> {
    let open = view.open.as_ref();
    let mut actions = Vec::new();
    if let Some(open) = open {
        if approve_precheck(Some(open), &open.to, true).is_ok() {
            actions.push(AvailableAction::Approve {
                version: open.to.clone(),
                warnings: open.warnings.clone(),
                release_notes_url: open.release_notes_url.clone(),
            });
        }
        if matches!(open.status, RolloutStatus::Active | RolloutStatus::Failed) {
            actions.push(AvailableAction::Cancel);
        }
        if open.kind == RolloutKind::Upgrade
            && open.status == RolloutStatus::Active
            && open.requires_finalization()
            && finalize_precheck(Some(open), &view.nodes, &open.to).is_ok()
        {
            actions.push(AvailableAction::Finalize {
                target: open.to.clone(),
            });
        }
    }
    let agents: Vec<AgentObservation> =
        view.agents.iter().map(|agent| agent.observation.clone()).collect();
    match restart_precheck(open, &view.nodes, &agents) {
        Ok(version) => actions.push(AvailableAction::Restart { version }),
        Err(reason) if open.is_none() => actions.push(AvailableAction::RestartBlocked { reason }),
        Err(_) => {}
    }
    actions
}
```

```rust
fn summary_of(cli: &Cli, client: &mut Client) -> Result<Option<(crate::OpenRollout, OpenSummary)>, AppError> {
    Ok(open_rollout(cli, client)?.map(|rollout| {
        let summary = OpenSummary::from(&rollout);
        (rollout, summary)
    }))
}

pub fn approve(
    cli: &Cli,
    client: &mut Client,
    actor: &Actor,
    version: &str,
    accept_warnings: bool,
) -> Result<String, AppError> {
    let target = parse_cockroach_version(version)?;
    let open = summary_of(cli, client)?;
    approve_precheck(open.as_ref().map(|(_, summary)| summary), &target, accept_warnings)
        .map_err(AppError::Message)?;
    let (rollout, _) = open.expect("the precheck passed, so a rollout is open");

    if rollout.requires_finalization() {
        // Without this, CockroachDB finalizes on its own the moment the last
        // node restarts, and the downgrade window closes before anyone looks.
        let line = major_line_string(&rollout.manifest.current_version);
        client.batch_execute(&format!(
            "SET CLUSTER SETTING cluster.preserve_downgrade_option = '{line}'"
        ))?;
    }

    let mut manifest = rollout.manifest;
    manifest.release_note_warnings_approved = accept_warnings;
    let schema = sql_ident(&cli.schema)?;
    let approver = actor.label(cli);
    let updated = client.execute(
        &format!(
            "
            UPDATE {schema}.rollouts
            SET status = 'active', approved_by = $2, approved_at = now(), manifest_json = $3
            WHERE id::STRING = $1 AND status = 'proposed'
            "
        ),
        &[&rollout.id, &approver, &serde_json::to_string(&manifest)?],
    )?;
    if updated != 1 {
        return Err(AppError::Message(
            "the proposal changed while approving; reload status".to_string(),
        ));
    }
    events::note(
        cli,
        client,
        actor.source(),
        "rollout_approved",
        &format!(
            "current={} target={} by={approver}",
            manifest.current_version, manifest.target_version
        ),
    )?;
    Ok(format!(
        "approved {} -> {}; agents will upgrade one node at a time",
        manifest.current_version, manifest.target_version
    ))
}

pub fn cancel(cli: &Cli, client: &mut Client, actor: &Actor, reason: &str) -> Result<String, AppError> {
    let Some(rollout) = open_rollout(cli, client)? else {
        return Ok("no open rollout".to_string());
    };
    set_rollout_status(cli, client, &rollout.id, RolloutStatus::Cancelled, Some(reason))?;
    events::note(
        cli,
        client,
        actor.source(),
        "rollout_cancelled",
        &format!(
            "kind={} target={} reason={reason} by={}",
            rollout.kind,
            rollout.manifest.target_version,
            actor.label(cli)
        ),
    )?;
    let mut message = format!(
        "cancelled {} {} rollout to {}",
        rollout.status, rollout.kind, rollout.manifest.target_version
    );
    if rollout.kind == RolloutKind::Upgrade
        && rollout.status != RolloutStatus::Proposed
        && rollout.requires_finalization()
    {
        message.push_str(
            "; cluster.preserve_downgrade_option is still set, so already-upgraded nodes can be \
             rolled back; RESET it only once every node runs one version",
        );
    }
    Ok(message)
}

pub fn finalize(
    cli: &Cli,
    client: &mut Client,
    actor: &Actor,
    target_version: &str,
    dry_run: bool,
) -> Result<String, AppError> {
    let version = parse_cockroach_version(target_version)?;
    let open = summary_of(cli, client)?;
    let nodes = cluster_nodes(client)?;
    finalize_precheck(open.as_ref().map(|(_, summary)| summary), &nodes, &version)
        .map_err(AppError::Message)?;
    let line = major_line_string(&version);
    if dry_run {
        return Ok(format!(
            "dry run: RESET CLUSTER SETTING cluster.preserve_downgrade_option; \
             SET CLUSTER SETTING version = '{line}'"
        ));
    }
    finalize_cluster(cli, client, &version)?;
    if let Some((rollout, _)) = open.filter(|(rollout, _)| {
        rollout.kind == RolloutKind::Upgrade && rollout.manifest.target_version == version
    }) {
        set_rollout_status(cli, client, &rollout.id, RolloutStatus::Finalized, None)?;
    }
    events::note(
        cli,
        client,
        actor.source(),
        "finalized",
        &format!("cluster_version={line} by={}", actor.label(cli)),
    )?;
    Ok(format!(
        "finalized cluster version {line}; downgrading to the previous release line is no longer possible"
    ))
}

pub fn restart_cluster(cli: &Cli, client: &mut Client, actor: &Actor) -> Result<String, AppError> {
    let open = summary_of(cli, client)?;
    let nodes = cluster_nodes(client)?;
    let agents = cluster_view::agent_observations(cli, client)?;
    let version = restart_precheck(open.as_ref().map(|(_, summary)| summary), &nodes, &agents)
        .map_err(AppError::Message)?;

    // A restart stores an ordinary manifest so manifest_json stays NOT NULL
    // and open_rollout keeps one shape: same version both ends, nothing to
    // download, nothing to warn about.
    let manifest = RolloutManifest {
        schema_version: 1,
        created_unix: unix_time()?,
        current_version: version.clone(),
        target_version: version.clone(),
        release_notes_url: String::new(),
        release_note_warnings: Vec::new(),
        release_note_warnings_approved: true,
        artifacts: Vec::new(),
    };
    let schema = sql_ident(&cli.schema)?;
    let by = actor.label(cli);
    let inserted = client.execute(
        &format!(
            "
            INSERT INTO {schema}.rollouts
                (kind, status, current_version, target_version, manifest_json,
                 created_by, approved_by, approved_at)
            SELECT 'restart', 'active', $1, $1, $2, $3, $3, now()
            WHERE NOT EXISTS (
                SELECT 1 FROM {schema}.rollouts WHERE status IN ('proposed', 'active', 'failed')
            )
            "
        ),
        &[&version.to_string(), &serde_json::to_string(&manifest)?, &by],
    )?;
    if inserted != 1 {
        return Err(AppError::Message(
            "another rollout opened while starting the restart; reload and try again".to_string(),
        ));
    }
    events::note(
        cli,
        client,
        actor.source(),
        "restart_started",
        &format!("version={version} nodes={} by={by}", nodes.len()),
    )?;
    Ok(format!(
        "rolling restart of {} nodes on {version} started; agents restart one node at a time",
        nodes.len()
    ))
}
```

```rust
/// every restart, so it tells a fresh observation from a stale one.
fn own_started_at(client: &mut Client) -> Result<i64, AppError> {
    let row = client.query_one(
        "
        SELECT (extract(epoch FROM started_at) * 1000000)::INT8
        FROM crdb_internal.gossip_nodes
        WHERE node_id = crdb_internal.node_id()
        ",
        &[],
    )?;
    Ok(row.get(0))
}

fn restarted_rollout_id(

/// Waits until this node is live on `expected` with a start time newer than
/// `started_before`. Reconnects each poll because the node went away.
fn wait_for_restart(
    cli: &Cli,
    expected: &Version,
    started_before: i64,
    timeout: Duration,
) -> Result<(), AppError> {
    let deadline = SystemTime::now() + timeout;
    let mut last = String::from("no observation yet");
    while SystemTime::now() < deadline {
        thread::sleep(Duration::from_secs(HEALTH_POLL_SECONDS));
        let observed = db_client(cli).and_then(|mut client| {
            Ok((own_node_observation(&mut client)?, own_started_at(&mut client)?))
        });
        match observed {
            Ok((node, started)) if restarted_on(expected, started_before, &node, started) => {
                return Ok(());
            }
            Ok((node, started)) => {
                last = format!(
                    "node {} live={} version={} started_at_us={started} (before {started_before})",
                    node.node_id,
                    node.is_live,
                    node.version
                        .map(|version| version.to_string())
                        .unwrap_or_else(|| "unknown".to_string())
                );
            }
            Err(error) => last = error.to_string(),
        }
    }
    Err(AppError::Message(format!(
        "node did not restart on {expected} within {}s; last: {last}",
        timeout.as_secs()
    )))
}
```

```rust
/// Restarts this node once per restart rollout, under the install lease and
/// health gate. Nothing is swapped, so failure has nothing to roll back: the
/// rollout halts as `failed` for an operator, like a failed upgrade.
fn follower_restart(
    cli: &Cli,
    client: &mut Client,
    agent_id: &str,
    rollout: &OpenRollout,
    dry_run: bool,
) -> Result<(), AppError> {
    let restarted = restarted_rollout_id(cli, client, agent_id)?;
    if restart_action(&rollout.id, restarted.as_deref()) == RestartAction::AlreadyRestarted {
        if !dry_run {
            release_lease(cli, client, INSTALL_LEASE, agent_id)?;
        }
        return Ok(());
    }
    let running = own_node_version(client)?;
    if dry_run {
        println!("dry run: would take the install lease and restart this node on {running}");
        return Ok(());
    }

    let service = service_name(cli)?;
    let lease_seconds = cli.restart_timeout_seconds + INSTALL_LEASE_EXTRA_SECONDS;
    let lease = acquire_lease(cli, client, INSTALL_LEASE, agent_id, lease_seconds)?;
    if !lease.is_leader {
        return record_agent_state(
            cli,
            client,
            agent_id,
            "queued",
            &running,
            &rollout.id,
            Some(&format!("install lease held by {}", lease.holder_id)),
        );
    }
    if let Err(reason) = health_verdict(client) {
        record_agent_state(
            cli,
            client,
            agent_id,
            "waiting_for_health",
            &running,
            &rollout.id,
            Some(&reason),
        )?;
        events::note(cli, client, Source::Agent, "gate_wait", &reason)?;
        return release_lease(cli, client, INSTALL_LEASE, agent_id);
    }

    record_agent_state(cli, client, agent_id, "restarting", &running, &rollout.id, None)?;
    let started_before = own_started_at(client)?;
    events::note(
        cli,
        client,
        Source::Agent,
        "restart_begin",
        &format!("service={service} version={running}"),
    )?;
    let timeout = Duration::from_secs(cli.restart_timeout_seconds);
    let outcome = run_systemctl("restart", service)
        .and_then(|()| wait_for_restart(cli, &running, started_before, timeout));

    // The node restarted, so the old connection is gone.
    *client = reconnect(cli)?;
    match outcome {
        Ok(()) => {
            mark_restarted(cli, client, agent_id, &rollout.id)?;
            record_agent_state(cli, client, agent_id, "complete", &running, &rollout.id, None)?;
            events::note(cli, client, Source::Agent, "restarted", &format!("version={running}"))?;
            release_lease(cli, client, INSTALL_LEASE, agent_id)
        }
        Err(error) => {
            let message = error.to_string();
            set_rollout_status(
                cli,
                client,
                &rollout.id,
                RolloutStatus::Failed,
                Some(&format!("{agent_id}: {message}")),
            )?;
            record_agent_state(
                cli,
                client,
                agent_id,
                "failed",
                &running,
                &rollout.id,
                Some(&message),
            )?;
            events::note(cli, client, Source::Agent, "restart_failed", &message)?;
            release_lease(cli, client, INSTALL_LEASE, agent_id)?;
            Err(error)
        }
    }
}
```

```js
// Refreshes <main id="main"> every 10 seconds. Skips while the operator is
// typing so a refresh never wipes a half-filled form. The page works fully

(function () {
  "use strict";

  function editing() {
    var el = document.activeElement;
    return !!el && (el.tagName === "INPUT" || el.tagName === "TEXTAREA" || el.tagName === "SELECT");
  }

  function refresh() {
    if (editing()) return;
    fetch("/", { credentials: "same-origin", cache: "no-store" })
      .then(function (response) {
        if (response.redirected && new URL(response.url).pathname === "/login") {
          window.location.assign("/login");
          return null;
        }
        return response.ok ? response.text() : null;
      })
      .then(function (html) {
        if (!html || editing()) return;
        var next = new DOMParser().parseFromString(html, "text/html").getElementById("main");
        var current = document.getElementById("main");
        if (next && current) current.replaceWith(next);
      })
      .catch(function () {});
  }

  if (document.getElementById("main")) setInterval(refresh, 10000);
})();
```

```rust
/// A table whose cells are plain text; every cell is escaped here.
fn table(heading: &str, columns: &[&str], rows: Vec<Vec<String>>, empty: &str) -> String {
    let mut html = format!("<section><h2>{}</h2>", escape(heading));
    if rows.is_empty() {
        let _ = write!(html, "<p>{}</p></section>", escape(empty));
        return html;
    }
    html.push_str("<div class=\"scroll\"><table><thead><tr>");
    for column in columns {
        let _ = write!(html, "<th>{}</th>", escape(column));
    }
    html.push_str("</tr></thead><tbody>");
    for row in rows {
        html.push_str("<tr>");
        for cell in row {
            let _ = write!(html, "<td>{}</td>", escape(&cell));
        }
        html.push_str("</tr>");
    }
    html.push_str("</tbody></table></div></section>");
    html
}
```

```rust
use std::collections::HashMap;
use std::net::IpAddr;
use std::sync::Mutex;
use std::time::{Duration, Instant};

use argon2::{Argon2, PasswordHash, PasswordHasher, PasswordVerifier};
use rand::Rng;
use sha2::{Digest, Sha256};
use subtle::ConstantTimeEq;

pub const MIN_PASSWORD_CHARS: usize = 12;
pub const SESSION_COOKIE: &str = "crra_session";
pub const MAX_FAILURES: usize = 5;
pub const FAILURE_WINDOW: Duration = Duration::from_secs(60);

/// argon2id with the crate defaults and a fresh random salt.
pub fn hash_password(password: &str) -> Result<String, String> {
    if password.chars().count() < MIN_PASSWORD_CHARS {
        return Err(format!(
            "the UI password must be at least {MIN_PASSWORD_CHARS} characters"
        ));
    }
    Argon2::default()
        .hash_password(password.as_bytes())
        .map(|hash| hash.to_string())
        .map_err(|error| format!("could not hash the password: {error}"))
}

pub fn verify_password(password: &str, phc: &str) -> bool {
    PasswordHash::new(phc).is_ok_and(|parsed| {
        Argon2::default()
            .verify_password(password.as_bytes(), &parsed)
            .is_ok()
    })
}

pub fn random_token() -> String {
    let mut bytes = [0_u8; 32];
    rand::rng().fill_bytes(&mut bytes);
    hex::encode(bytes)
}

/// Sessions are stored by this hash, so a leaked `ui_sessions` table does
/// not hand out live cookies.
pub fn token_sha256(token: &str) -> String {
    hex::encode(Sha256::digest(token.as_bytes()))
}

pub fn csrf_matches(expected: &str, given: &str) -> bool {
    !expected.is_empty()
        && expected.len() == given.len()
        && bool::from(expected.as_bytes().ct_eq(given.as_bytes()))
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Session {
    pub csrf_token: String,
    pub expires_unix: i64,
}

pub fn session_live(session: &Session, now_unix: i64) -> bool {
    now_unix < session.expires_unix
}

/// Value of cookie `name` in one `Cookie:` header.
pub fn cookie_value<'a>(header: &'a str, name: &str) -> Option<&'a str> {
    header.split(';').map(str::trim).find_map(|pair| {
        let (key, value) = pair.split_once('=')?;
        (key == name).then_some(value)
    })
}

/// Per-IP failed-login counter, in memory on each node. A speed bump against
/// guessing, not a distributed lockout.
#[derive(Default)]
pub struct LoginLimiter {
    failures: Mutex<HashMap<IpAddr, Vec<Instant>>>,
}

impl LoginLimiter {
    pub fn new() -> Self {
        Self::default()
    }

    pub fn blocked(&self, ip: IpAddr, now: Instant) -> bool {
        let failures = self.failures.lock().unwrap_or_else(|poisoned| poisoned.into_inner());
        failures.get(&ip).is_some_and(|times| {
            times
                .iter()
                .filter(|time| now.duration_since(**time) < FAILURE_WINDOW)
                .count()
                >= MAX_FAILURES
        })
    }

    pub fn record_failure(&self, ip: IpAddr, now: Instant) {
        let mut failures = self.failures.lock().unwrap_or_else(|poisoned| poisoned.into_inner());
        failures.retain(|_, times| {
            times.retain(|time| now.duration_since(*time) < FAILURE_WINDOW);
            !times.is_empty()
        });
        failures.entry(ip).or_default().push(now);
    }

    pub fn record_success(&self, ip: IpAddr) {
        self.failures
            .lock()
            .unwrap_or_else(|poisoned| poisoned.into_inner())
            .remove(&ip);
    }
}
```

```rust
use std::path::{Path, PathBuf};
use std::process::{Command, Stdio};
use std::sync::Arc;

use rustls::pki_types::pem::PemObject;
use rustls::pki_types::{CertificateDer, PrivateKeyDer};

/// Picks the certs dir: the override, else `--certs-dir` from the unit's
/// argv, resolved against `WorkingDirectory` (systemd's `/` if unset).
pub fn choose_certs_dir(
    override_dir: Option<&Path>,
    exec_start: &str,
    working_dir: Option<&str>,
) -> Result<PathBuf, String> {
    if let Some(dir) = override_dir {
        return Ok(dir.to_path_buf());
    }
    let mut words = exec_start.split_whitespace();
    let mut found = None;
    while let Some(word) = words.next() {
        if let Some(value) = word.strip_prefix("--certs-dir=") {
            found = Some(value.to_string());
        } else if word == "--certs-dir" {
            found = words.next().map(str::to_string);
        }
    }
    let dir = PathBuf::from(found.ok_or_else(|| {
        "the CockroachDB unit has no --certs-dir; set CROACH_ROLLOUT_UI_CERTS_DIR".to_string()
    })?);
    if dir.is_absolute() {
        return Ok(dir);
    }
    let base = working_dir
        .map(|dir| dir.trim_start_matches(['-', '!']))
        .filter(|dir| !dir.is_empty())
        .unwrap_or("/");
    Ok(Path::new(base).join(dir))
}

pub fn resolve_certs_dir(override_dir: Option<&Path>, service: &str) -> Result<PathBuf, String> {
    if let Some(dir) = override_dir {
        return Ok(dir.to_path_buf());
    }
    let output = Command::new("systemctl")
        .args([
            "show",
            "--property=ExecStart",
            "--property=WorkingDirectory",
            service,
        ])
        .stdin(Stdio::null())
        .output()
        .map_err(|error| format!("could not run systemctl show: {error}"))?;
    if !output.status.success() {
        return Err(format!(
            "systemctl show {service} failed: {}",
            String::from_utf8_lossy(&output.stderr).trim()
        ));
    }
    let text = String::from_utf8_lossy(&output.stdout);
    let mut exec_start = "";
    let mut working_dir = None;
    for line in text.lines() {
        if let Some(value) = line.strip_prefix("ExecStart=") {
            exec_start = value;
        } else if let Some(value) = line.strip_prefix("WorkingDirectory=") {
            working_dir = Some(value);
        }
    }
    choose_certs_dir(None, exec_start, working_dir).map_err(|error| format!("{service}: {error}"))
}

/// TLS 1.2 and 1.3 only, `ring` provider, HTTP/1.1. Accepts PKCS#1, PKCS#8
/// and SEC1 keys; `cockroach cert` writes PKCS#1.
pub fn server_config(cert_pem: &[u8], key_pem: &[u8]) -> Result<rustls::ServerConfig, String> {
    let certs = CertificateDer::pem_slice_iter(cert_pem)
        .collect::<Result<Vec<_>, _>>()
        .map_err(|error| format!("bad certificate PEM: {error}"))?;
    if certs.is_empty() {
        return Err("no certificate found in the PEM".to_string());
    }
    let key = PrivateKeyDer::from_pem_slice(key_pem)
        .map_err(|error| format!("bad private key PEM: {error}"))?;
    let provider = Arc::new(rustls::crypto::ring::default_provider());
    let mut config = rustls::ServerConfig::builder_with_provider(provider)
        .with_protocol_versions(&[&rustls::version::TLS13, &rustls::version::TLS12])
        .map_err(|error| error.to_string())?
        .with_no_client_auth()
        .with_single_cert(certs, key)
        .map_err(|error| format!("certificate and key do not form a usable pair: {error}"))?;
    config.alpn_protocols = vec![b"http/1.1".to_vec()];
    Ok(config)
}

pub fn load_server_config(dir: &Path) -> Result<rustls::ServerConfig, String> {
    let read = |name: &str| {
        let path = dir.join(name);
        std::fs::read(&path).map_err(|error| format!("cannot read {}: {error}", path.display()))
    };
    server_config(&read("node.crt")?, &read("node.key")?)
        .map_err(|error| format!("{}: {error}", dir.display()))
}
```

```rust
pub fn parse_action(name: &str, form: &HashMap<String, String>) -> Result<WebAction, String> {
    let field = |key: &str| form.get(key).map(|value| value.trim()).unwrap_or("");
    match name {
        "approve" if !field("version").is_empty() => Ok(WebAction::Approve {
            version: field("version").to_string(),
            accept_warnings: field("accept_warnings") == "on",
        }),
        "approve" => Err("the approval form is missing the version".to_string()),
        "cancel" if !field("reason").is_empty() => Ok(WebAction::Cancel {
            reason: field("reason").to_string(),
        }),
        "cancel" => Err("a reason is required to cancel".to_string()),
        "finalize" if !field("confirm_version").is_empty() => Ok(WebAction::Finalize {
            confirm_version: field("confirm_version").to_string(),
        }),
        "finalize" => Err("type the target version to confirm finalizing".to_string()),
        "restart" if field("confirm") == "restart" => Ok(WebAction::Restart),
        "restart" => Err("type restart to confirm a rolling restart".to_string()),
        other => Err(format!("unknown action: {other}")),
    }

/// Runs blocking work (DB, argon2) off the async workers. A panic inside
/// becomes an error string instead of taking the connection down.
pub(crate) async fn blocking<T, F>(work: F) -> Result<T, String>
where
    F: FnOnce() -> Result<T, String> + Send + 'static,
    T: Send + 'static,
{
    tokio::task::spawn_blocking(work)
        .await
        .map_err(|error| format!("internal error: {error}"))?
}

pub async fn serve(
    listener: TcpListener,
    state: routes::AppState,
    tls: rustls::ServerConfig,
) -> io::Result<()> {
    listener.set_nonblocking(true)?;
    let app = routes::router(state).into_make_service_with_connect_info::<SocketAddr>();
    axum_server::from_tcp_rustls(listener, RustlsConfig::from_config(Arc::new(tls)))?
        .serve(app)
        .await
}

/// Binds on the caller's thread, so a bad address or a port in use is
/// reported at startup, then serves on a dedicated thread with its own
/// runtime. The daemon never waits on it.
pub fn spawn(
    listen: SocketAddr,
    state: routes::AppState,
    tls: rustls::ServerConfig,
) -> io::Result<thread::JoinHandle<()>> {
    let listener = TcpListener::bind(listen)?;
    thread::Builder::new()
        .name("web-ui".to_string())
        .spawn(move || {
            let runtime = match tokio::runtime::Builder::new_multi_thread()
                .worker_threads(2)
                .thread_name("web-ui-worker")
                .enable_all()
                .build()
            {
                Ok(runtime) => runtime,
                Err(error) => {
                    eprintln!("ui disabled: could not start the runtime: {error}");
                    return;
                }
            };
            if let Err(error) = runtime.block_on(serve(listener, state, tls)) {
                eprintln!("ui stopped: {error}");
            }
        })
}
```

```rust
async fn security_headers(request: Request, next: Next) -> Response {
    let mut response = next.run(request).await;
    let headers = response.headers_mut();
    for (name, value) in [
        (
            "content-security-policy",
            "default-src 'self'; form-action 'self'; frame-ancestors 'none'",
        ),
        ("x-frame-options", "DENY"),
        ("referrer-policy", "no-referrer"),
        ("x-content-type-options", "nosniff"),
        ("cache-control", "no-store"),
    ] {

    response

fn cookie<'a>(headers: &'a HeaderMap, name: &str) -> Option<&'a str> {
    headers
        .get_all(header::COOKIE)
        .iter()
        .filter_map(|value| value.to_str().ok())
        .find_map(|value| auth::cookie_value(value, name))
}

fn set_cookie(name: &str, value: &str, max_age: Option<u64>) -> String {
    let max_age = max_age.map(|secs| format!("; Max-Age={secs}")).unwrap_or_default();
    format!("{name}={value}; Secure; HttpOnly; SameSite=Strict; Path=/{max_age}")
}

fn flash_cookie(message: &str) -> String {
    let mut end = message.len().min(FLASH_MAX_BYTES);
    while !message.is_char_boundary(end) {
        end -= 1;
    }
    set_cookie(FLASH_COOKIE, &hex::encode(&message[..end]), None)
}

fn read_flash(headers: &HeaderMap) -> Option<String> {
    cookie(headers, FLASH_COOKIE)
        .and_then(|value| hex::decode(value).ok())
        .and_then(|bytes| String::from_utf8(bytes).ok())
}

        response.headers_mut().append(header::SET_COOKIE, value);

}

async fn session_of(
    state: &AppState,
    headers: &HeaderMap,
) -> Result<Option<(String, Session)>, String> {
    let Some(token) = cookie(headers, auth::SESSION_COOKIE) else {
        return Ok(None);

}

        Ok(None) => page(StatusCode::FORBIDDEN, render::password_unset_page()),
        Ok(Some(false)) => {
            state.limiter.record_failure(ip, Instant::now());
            page(StatusCode::UNAUTHORIZED, render::login_page(Some("wrong password")))
        }
        Ok(Some(true)) => {
            state.limiter.record_success(ip);
            let token = auth::random_token();
            let csrf = auth::random_token();
            let key = auth::token_sha256(&token);
            let ttl = state.session_ttl;
            let client_ip = ip.to_string();
            let backend = state.backend.clone();
            let created = blocking(move || {
                backend.create_session(&key, &csrf, ttl, &client_ip)?;
                backend.record_event("login", &format!("ip={client_ip}"))
            })
            .await;
            match created {
                Ok(()) => see_other(
                    "/",
                    &[set_cookie(auth::SESSION_COOKIE, &token, Some(ttl.as_secs()))],
                ),
                Err(error) => page(StatusCode::SERVICE_UNAVAILABLE, render::db_unreachable(&error)),
            }
        }
    }
}

fn forbidden() -> Response {
    page(
        StatusCode::FORBIDDEN,
        render::message_page(
            "Forbidden",
            "The form was stale or forged. Reload the dashboard and try again.",
        ),
    )
}

async fn action(
    State(state): State<AppState>,
    ConnectInfo(peer): ConnectInfo<SocketAddr>,
    Path(name): Path<String>,
    headers: HeaderMap,
    Form(form): Form<HashMap<String, String>>,
) -> Response {
    let session = match session_of(&state, &headers).await {
        Ok(Some((_, session))) => session,
        Ok(None) => return see_other("/login", &[]),
        Err(error) => return page(StatusCode::SERVICE_UNAVAILABLE, render::db_unreachable(&error)),
    };
    let ip = peer.ip().to_string();
    let given = form.get("csrf").map(String::as_str).unwrap_or("");
    if !auth::csrf_matches(&session.csrf_token, given) {
        let backend = state.backend.clone();
        let detail = format!("ip={ip} action={name}");
        // Best effort: the refusal stands even if the event cannot be written.
        let _ = blocking(move || backend.record_event("csrf_rejected", &detail)).await;
        return forbidden();
    }
    let message = match parse_action(&name, &form) {
        Err(error) => error,
        Ok(web_action) => {
            let backend = state.backend.clone();
            let actor = Actor::Web { ip };
            blocking(move || backend.act(web_action, &actor))
                .await
                .unwrap_or_else(|error| error)
        }
    };
    see_other("/", &[flash_cookie(&message)])
}

async fn logout(
    State(state): State<AppState>,
    headers: HeaderMap,
    Form(form): Form<HashMap<String, String>>,
) -> Response {
    let clear = set_cookie(auth::SESSION_COOKIE, "", Some(0));
    let (key, session) = match session_of(&state, &headers).await {
        Ok(Some(found)) => found,
        Ok(None) => return see_other("/login", &[clear]),
        Err(error) => return page(StatusCode::SERVICE_UNAVAILABLE, render::db_unreachable(&error)),
    };
    let given = form.get("csrf").map(String::as_str).unwrap_or("");
    if !auth::csrf_matches(&session.csrf_token, given) {
        return forbidden();
    }
    let backend = state.backend.clone();
    if let Err(error) = blocking(move || backend.delete_session(&key)).await {
        return page(StatusCode::SERVICE_UNAVAILABLE, render::db_unreachable(&error));
    }
    see_other("/login", &[clear])
}

async fn css() -> impl IntoResponse {
    ([(header::CONTENT_TYPE, "text/css; charset=utf-8")], render::APP_CSS)
}

async fn js() -> impl IntoResponse {
    (
        [(header::CONTENT_TYPE, "text/javascript; charset=utf-8")],
        render::APP_JS,
    )
```

```rust
impl Backend for DbBackend {
    fn password_hash(&self) -> Result<Option<String>, String> {
        let schema = self.schema()?;
        let rows = self
            .client()?
            .query(&format!("SELECT password_hash FROM {schema}.ui_auth WHERE id = 1"), &[])
            .map_err(text)?;
        Ok(rows.first().map(|row| row.get(0)))
    }

    fn create_session(
        &self,
        token_sha256: &str,
        csrf_token: &str,
        ttl: Duration,
        client_ip: &str,
    ) -> Result<(), String> {
        let schema = self.schema()?;
        let seconds = ttl.as_secs() as i64;
        self.client()?
            .execute(
                &format!(
                    "
                    INSERT INTO {schema}.ui_sessions (token_sha256, csrf_token, expires_at, client_ip)
                    VALUES ($1, $2, now() + ($3::INT8 * INTERVAL '1 second'), $4)
                    "
                ),
                &[&token_sha256, &csrf_token, &seconds, &client_ip],
            )
            .map_err(text)?;
        Ok(())
    }

    fn session(&self, token_sha256: &str) -> Result<Option<auth::Session>, String> {
        let schema = self.schema()?;
        let rows = self
            .client()?
            .query(
                &format!(
                    "
                    SELECT csrf_token, extract(epoch FROM expires_at)::INT8
                    FROM {schema}.ui_sessions
                    WHERE token_sha256 = $1 AND expires_at > now()
                    "
                ),
                &[&token_sha256],
            )
            .map_err(text)?;
        Ok(rows.first().map(|row| auth::Session {
            csrf_token: row.get(0),
            expires_unix: row.get(1),
        }))
    }

    fn delete_session(&self, token_sha256: &str) -> Result<(), String> {
        let schema = self.schema()?;
        self.client()?
            .execute(
                &format!("DELETE FROM {schema}.ui_sessions WHERE token_sha256 = $1"),
                &[&token_sha256],
            )
            .map_err(text)?;
        Ok(())
    }

    fn record_event(&self, kind: &str, detail: &str) -> Result<(), String> {
        let mut client = self.client()?;
        events::record_event(&self.cli, &mut client, Source::Web, kind, detail).map_err(text)
    }

    fn view(&self) -> Result<ClusterView, String> {
        let mut client = self.client()?;
        cluster_view::load(&self.cli, &mut client).map_err(text)
    }

    fn act(&self, action: WebAction, actor: &Actor) -> Result<String, String> {
        let mut client = self.client()?;
        let cli = &self.cli;
        match action {
            WebAction::Approve {
                version,
                accept_warnings,
            } => ops::approve(cli, &mut client, actor, &version, accept_warnings),
            WebAction::Cancel { reason } => ops::cancel(cli, &mut client, actor, &reason),
            WebAction::Finalize { confirm_version } => {
                ops::finalize(cli, &mut client, actor, &confirm_version, false)
            }
            WebAction::Restart => ops::restart_cluster(cli, &mut client, actor),
        }
        .map_err(text)
    }
}
```

```rust
        return Ok(None);

/// The UI's certs dir and TLS config, the same resolution `self-check` reports.
fn ui_tls(cli: &Cli) -> Result<(PathBuf, rustls::ServerConfig), String> {
    let dir = match &cli.ui_certs_dir {
        Some(dir) => dir.clone(),
        None => web::tls::resolve_certs_dir(
            None,
            service_name(cli).map_err(|error| error.to_string())?,
        )?,
    };
    let config = web::tls::load_server_config(&dir)?;
    Ok((dir, config))
}

/// Starts the UI thread. Every failure leaves the UI off and the daemon
/// running: rollouts never depend on the UI, and it never falls back to HTTP.
fn start_web_ui(cli: &Cli) -> Result<(), AppError> {
    let listen = match ui_listen_addr(&cli.ui_listen) {
        Ok(Some(listen)) => listen,
        Ok(None) => return audit(cli, "ui_disabled", "CROACH_ROLLOUT_UI_LISTEN=off"),
        Err(reason) => {
            eprintln!("ui disabled: {reason}");
            return audit(cli, "ui_disabled", &reason);
        }
    };
    let tls = match ui_tls(cli) {
        Ok((_, config)) => config,
        Err(reason) => {
            eprintln!("ui disabled: {reason}");
            return audit(cli, "ui_disabled", &reason);
        }
    };
    let state = web::routes::AppState {
        backend: Arc::new(web::db::DbBackend::new(cli.clone())),
        limiter: Arc::new(web::auth::LoginLimiter::new()),
        session_ttl: Duration::from_secs(cli.ui_session_hours.saturating_mul(3600)),
    };
    match web::spawn(listen, state, tls) {
        Ok(_) => audit(cli, "ui_started", &format!("listen={listen}")),
        Err(error) => {
            let reason = format!("cannot listen on {listen}: {error}");
            eprintln!("ui disabled: {reason}");
            audit(cli, "ui_disabled", &reason)
        }
    }
}

fn set_ui_password_command(cli: &Cli) -> Result<(), AppError> {
    let password = read_new_password()?;

    ensure_schema(cli, &mut client)?;

fn read_new_password() -> Result<String, AppError> {
    if io::stdin().is_terminal() {
        let first = rpassword::prompt_password("New UI password: ")?;
        let second = rpassword::prompt_password("Repeat it: ")?;
        if first != second {
            return Err(AppError::Message("the passwords do not match".to_string()));
        }
        return Ok(first);
    }
    let mut line = String::new();
    io::stdin().read_line(&mut line)?;
    Ok(line.trim_end_matches(['\r', '\n']).to_string())
}
```

```markdown
## Web UI

- **Scope:** one shared operator password, intended for a trusted LAN.
  There are no accounts or roles.
- **Password storage:** the password is stored only as an argon2id hash
  in `<schema>.ui_auth`.
- **Sessions:** the session cookie `crra_session` is `Secure`, `HttpOnly`
  and `SameSite=Strict`, and lasts `CROACH_ROLLOUT_UI_SESSION_HOURS`. The
  database stores only the cookie's SHA-256.
- **CSRF:** every state-changing form carries a per-session CSRF token,
  compared in constant time. A mismatch returns 403 and records a
  `csrf_rejected` event.
- **TLS:** TLS 1.2 or 1.3, using the node's own CockroachDB certificate.
  The UI never serves plain HTTP.
- **Security headers:** `Content-Security-Policy` (`default-src 'self'`,
  no framing), `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`,
  `X-Content-Type-Options: nosniff` and `Cache-Control: no-store`.
- **Lockout:** after 5 failed logins from one IP within 60 seconds, that
  node answers 429 for the rest of the minute.
  - The counter is in memory on each node, so it is a speed bump, not a
    cluster-wide lockout.
  - Use a long password.
- **Event log:** logins, CSRF rejections, password changes and every
  action are recorded in the cluster-wide `<schema>.events` table, as well
  as each host's audit log.
```
